# Code of conduct

## Our standard

Participation should be welcoming, patient, and focused on improving the
project. Treat contributors with respect regardless of experience, background,
identity, or whether their work was produced with AI assistance.

Constructive behaviour includes explaining technical concerns clearly,
crediting other people's work, accepting correction, protecting private data,
and helping first-time contributors understand the project's boundaries.

Harassment, personal attacks, discriminatory language, deliberate exposure of
private information, and repeated disruption are not acceptable.

## Enforcement

Project maintainers may edit or remove contributions and comments that violate
these standards, and may temporarily or permanently restrict participation.
Reports should use the private contact method in [SECURITY.md](SECURITY.md)
when public discussion would expose a person or sensitive information.

Maintainers will handle reports as privately and fairly as practical. This code
applies in repository spaces and when someone is representing the project in a
public community.
